# Agent Entry Prompts — ENH-E5

本directoryのpromptは、Execution Agentへ与えるnormative contextを最小・明確にする。

- SINGLE_EXECUTION Coding Agent: 06のみ
- Work Package Coding Agent: assigned Pxxのみ
- Test / Audit Agent: 07のみ（Implementation Completion Reportはcandidate identity evidence）
- Remediation Agent: current effective 08/Rxxのみ

Agentへ複数のPlanning/contract文書を読ませ、どれが正しいかを推論させない。
