### 1.2. Discovery

#### 1.2.1. 第一セクション（タイトルがないので便宜上こう呼ぶ）

- Feature columns
    - Feature columns にて項目を選ぶ際、生のテキストを入力するのではなく選択画面から選べるようにしてほしい
        - テキストフォームの横にボタンを配置
        - ボタンを押すと項目選択用のポップアップ画面が出る。
        - 当該画面では選択したデータセットに含まれている列がリストアップされ、チェックボックスで選べるようになっている
        - 選択してポップアップ画面を閉じると、使用する列のリスト（feature columns）がカンマ区切りで入力されている
        - テキストフォームに値が入力された状態で項目選択用ポップアップ画面を開くと、以下の挙動となる
            - テキストフォームに入力された列名が存在する場合、当該列名にチェックが入った状態となる
            - テキストフォームに入力された列名が存在しない場合、チェックが入らない状態となる
- アウトカム（新規項目追加）
    - アウトカムとして想定している列を選べるようにしてほしい。これは下記のマーメイド図で表現する際に、一番右にoutcomeノードが来てほしいからである。
    - 選択したデータセットを元に、ドロップダウンメニューで選択できるようにする
    - Inference ページの [アウトカム] は廃止

#### 1.2.2. Graph Results

**「チャートのグラフ」と「DAGのグラフ」の混同を避けるため、「DAGのグラフ」についてはDAGと表現している**

- 表示対象行
    - 現状では、因果探索結果のDAG（=Graph result）のみを表示しているが、DAGから派生させた子DAGも含めて表示すること

- 各 Graph Results 行
    - 行の表示項目は以下とすること
        - チェックボックス
        - FIXEDフラグ
        - 親グラフ情報
        - STATUS
        - Summary
        - [グラフを確認/編集する]ボタン
    - [グラフを確認/編集する]ボタン押下時の挙動
       - オーバーレイのモーダル画面が立ち上がる。これを[グラフ確認/編集モーダル画面]と呼ぶ
       - [グラフ確認/編集モーダル画面]は以下の項目と挙動を持つ
           - マーメイド図のような形でDAGを視覚的に表現される
           -  `Graph Version editor`  に表示されるノードとエッジのリストが、DAGマーメイド図の下部に表示される
           - `Graph Version editor` の持つ挙動を持つ、つまりエッジの削除/追加と選定・編集理由を入力してDAGを作成してFIXEDすることができる

- 選択した3件以上を比較
    - 2件以上で良い。
    - JSON形式で羅列されてもわからない。
    - ボタンを押下した際に、ポップアップでDAG比較画面が立ち上がること
    - DAG比較画面内では、タブ切り替えで複数のDAGを参照できること。

#### 1.2.3. Graph Version editor

- 本セクションが持つ挙動は、すべて[グラフ確認/編集モーダル画面]に移管し、本セクションは廃止とする
