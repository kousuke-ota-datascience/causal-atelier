# 1. フロントエンドにおける実装内容

まずは、最小限の機能として、以下ができるようになりたい。
フロントエンドプログラムを実装せよ

- プロジェクト詳細画面を確認
- プロジェクト詳細画面から、生データから分析用前処理済みデータを作成する流れまでを定義
- 使用するデータセットを指定し、因果探索を実施
- 因果探索結果のグラフを確認
- アルゴリズム別（PC/lingam等）のグラフ比較ができる
- 因果探索結果のグラフを保存し、それをもとに因果推論を実施
- 因果推論結果の結果を確認
