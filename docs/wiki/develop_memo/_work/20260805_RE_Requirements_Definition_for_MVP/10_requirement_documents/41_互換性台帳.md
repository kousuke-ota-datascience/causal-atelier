## 結論

実在client、owner、client fixture、廃止期限がすべて確認できる契約はなかった。したがってC2集合は空であり、Compatibility Adapterは実装しない。旧DB record、内部Python namespace、Legacy ORM、Legacy Worker protocol、Legacy Frontend内部状態は互換対象外である。

## 明示的な互換対象外

- `ariadne.application`、`ariadne.domain`、`ariadne.interfaces.api`、`ariadne.etl`の内部import path
- Legacy Configuration、Experiment、Pipeline、Stage、Attempt Resource
- 旧Metadata DBのrecord、ID、migration revision
- Legacy Frontend、Worker、内部queue protocol
- 科学的状態を欠落させる旧response形式

将来C2を追加する場合は、実在client、owner、変更困難性、request/response fixture、意味mapping、廃止期限、Contract Testの全項目を先に本台帳へ登録する。
