# 20 — Implementation Evidence

このdirectoryはCoding / Candidate Assemblyのevidenceを保存する。

Implementation reportはGate PASS authorityではない。

Trialごとに必要なpackage status/checkpointを作成し、Candidate Assembly後に1つのImplementation Completion ReportでFixed Trial Candidate SHAを固定する。

`READY_FOR_TEST` はIndependent Verificationへ渡せる状態を意味するだけで、Gate PASSではない。
