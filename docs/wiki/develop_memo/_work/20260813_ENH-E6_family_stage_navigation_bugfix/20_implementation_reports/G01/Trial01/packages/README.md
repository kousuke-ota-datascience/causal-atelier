# Package Evidence — 使用ガイド

Trial01 P01-P03のruntime status/checkpoint reportsを保存する。

Required separation:

- package START_SHA
- package checkpoint implementation commit
- evidence/report commit
- Fixed Trial Candidate (not created here by individual package Coding Agent)

Coding Agentはcanonical operator promptが指定するreport schema/pathに従う。Package reportはassigned PxxのevidenceでありG01 PASS/FAILを判定しない。
