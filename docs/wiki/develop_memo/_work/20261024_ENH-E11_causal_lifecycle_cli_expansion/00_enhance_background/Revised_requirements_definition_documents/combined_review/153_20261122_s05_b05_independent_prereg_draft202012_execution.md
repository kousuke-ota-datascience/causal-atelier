# S05 B05 independent science preregistration Schema — executable structural contract

Source: schema_drafts/internal_scientific/e11_science_prereg_draft1.schema.json. This is a design/review-only **Draft 2020-12** JSON Schema, not a deployed wire. Locally executed Python jsonschema 4.26 Draft202012Validator.check_schema on exact drafted content: PASS, plus 1 positive synthetic multi-metric *shape* instance and 13 deliberately invalid cases rejected: missing oracle/source/fixture proof, null hash, false pilot, alpha != 0.05, R=0, K=0, post-hoc T3, no family correction for K=3, CI metric field in POINT, duplicate/missing metric list, absent reviewer, unknown field. No scientific method or numerical acceptance PASS is implied.

Requires exact Method ID, estimand, independently sourced truth code/fixture and SHA256 fingerprints; exact isolated Backend lock and API probe; completed T2 pilot and seed/evidence fingerprints; preregistered T3 family size K, repetitions R, MCSE precision, FWER alpha .05, correction, one or more explicitly typed metric-family thresholds (simultaneous point+coverage+topology is valid), separate evidence, budget, reviewer identity and approval. All parameters must be explicitly fixed before confirmation, not populated with invented values.

External semantic checks required beyond Schema: method_id and metric_family must match the approved 41-ID source catalog; pilot/T3 seeds must be disjoint (cross-field hash inequality is insufficient to prove no overlapping seeds); independent reviewer must be genuinely independent; hashes must resolve to real files and content, source independent of Backend under test, K and multiplicity unit scientifically valid, thresholds justified by T2 and statistical design, complete negative cases/estimand, and T3 results evaluated against the predefined familywise rule. The schema deliberately does not assert those properties by virtue of a syntactic PASS.

The test positive instance is artificially constructed solely for Schema validation, contains fake hashes and artificial R/K, and is NOT stored as a candidate science registration. Every actual method registry entry still lacks independently reviewed references and preregistered quantitative choices. No S05 Freeze, G08 Science PASS, G10 Gate999 or Coding Authorization.

## 2026-11-22 multi-metric amendment

The first draft accidentally allowed exactly one metric object, which would be scientifically insufficient for AR (point bias + set shape + coverage) or heterogeneous treatment effect (surface bias + coverage) acceptance. Replaced with a strict nonempty unique `metrics[]` list of oneOf typed metric families; official Python jsonschema Draft202012.check_schema and 1 positive multi-metric instance + 13 negative shapes were **executed in a local review container** and passed. This test is not all 41 method-specific science. Cross-asset checker shall verify the required metric kinds for each Method/estimand, and the defined K family includes all corresponding hypotheses.
