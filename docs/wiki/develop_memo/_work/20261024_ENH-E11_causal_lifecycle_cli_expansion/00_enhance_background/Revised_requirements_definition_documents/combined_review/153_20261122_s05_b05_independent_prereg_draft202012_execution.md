# S05 B05 independent science preregistration Schema — executable structural contract

Source: schema_drafts/internal_scientific/e11_science_prereg_draft1.schema.json. This is a design/review-only **Draft 2020-12** JSON Schema, not a deployed wire. Locally executed Python jsonschema 4.26 Draft202012Validator.check_schema on exact drafted content: PASS, plus 1 positive synthetic *shape* instance and 12 deliberately invalid cases rejected: missing oracle/source/fixture proof, null hash, false pilot, alpha != 0.05, R=0, K=0, post-hoc T3, no family correction for K=3, CI metric field in topology, absent reviewer, unknown field. No scientific method or numerical acceptance PASS is implied.

Requires exact Method ID, estimand, independently sourced truth code/fixture and SHA256 fingerprints; exact isolated Backend lock and API probe; completed T2 pilot and seed/evidence fingerprints; preregistered T3 family size K, repetitions R, MCSE precision, FWER alpha .05, correction, metric-family thresholds, separate evidence, budget, reviewer identity and approval. All parameters must be explicitly fixed before confirmation, not populated with invented values.

External semantic checks required beyond Schema: method_id and metric_family must match the approved 41-ID source catalog; pilot/T3 seeds must be disjoint (cross-field hash inequality is insufficient to prove no overlapping seeds); independent reviewer must be genuinely independent; hashes must resolve to real files and content, source independent of Backend under test, K and multiplicity unit scientifically valid, thresholds justified by T2 and statistical design, complete negative cases/estimand, and T3 results evaluated against the predefined familywise rule. The schema deliberately does not assert those properties by virtue of a syntactic PASS.

The test positive instance is artificially constructed solely for Schema validation, contains fake hashes and artificial R/K, and is NOT stored as a candidate science registration. Every actual method registry entry still lacks independently reviewed references and preregistered quantitative choices. No S05 Freeze, G08 Science PASS, G10 Gate999 or Coding Authorization.
