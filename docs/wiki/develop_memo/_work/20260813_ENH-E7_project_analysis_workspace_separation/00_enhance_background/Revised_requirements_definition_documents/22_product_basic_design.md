# Product Basic Design — ENH-E7差分

```text
Projects
├─ Project List
├─ New Project
└─ Selected Project
   ├─ Overview
   ├─ Research Context
   ├─ Data
   └─ Results / Lineage

Analysis Workspace
├─ Analysis Context
├─ Family tabs
├─ Stage sidebar
└─ Stage Contents
```

Project ManagementとAnalysis Workspaceは異なるnavigation scopeを持つ別surfaceとする。
Current ProjectはAnalysis Workspace内ではread-onlyとする。
