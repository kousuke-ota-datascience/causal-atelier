## 1. 基本言語の変更

以下のディレクトリ配下に格納されるmdファイルで使用する言語は、日本語を基本とする

- 00_enhance_background
- 10_enhance_instruction

ただし、専門的な概念や技術用語など、日本語に翻訳しないほうが意味が通りやすいものは英語（あるいは元の言語）のままで問題ない

## 2. バージョニング

ファイル一式をまとめたzipファイルには、バージョンを表すpostfixをつけてほしい。

例）
```
20260813_ENH-E7_project_analysis_workspace_separation_v0.01.zip
```

ただし、

```
unzip 20260813_ENH-E7_project_analysis_workspace_separation_v0.01.zip
```

として、展開されるディレクトリ名称は

```
20260813_ENH-E7_project_analysis_workspace_separation
```
で問題ない
