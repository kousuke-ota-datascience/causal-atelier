# 29. Slide 29｜因果推論PoCの適用イメージ

## 29.1. Message

**因果PoCでは、キャンペーン対象者の購買率差を見るだけでなく、施策を実施したことによる増分効果を識別し、施策継続・対象選定へつなげる。**

## 29.2. Chart

**チャートタイトル:** 例：キャンペーン効果検証のPoCストーリー

Messageを説明・論証するための主たる視覚表現として、以下の構造を採用する。

### 29.2.1. Chart Structure

- 既存の論理フロー／概念図を主チャートとして用い、要素間の関係・順序が一目で追える構造にする。

```text
Business Question
キャンペーン投資を最適化したい
        ↓
Causal Question / Estimand
施策による購買の増分効果は何か
        ↓
Causal Design
Treatment / Outcome / Confounders / Time
        ↓
Identification / Estimation
比較可能性を作りEffect推定
        ↓
Diagnostics / Sensitivity
仮定と頑健性を確認
        ↓
Decision / Action
施策継続・対象・予算配分を判断
```

**PowerPoint上の配置・強調**

- 6段階の縦フローとし、Identification / Diagnosticsを省略しない。
- 最終段をDecision / Actionとして強調する。
- 予測ケースと同じレイアウト系統にして比較しやすくする。

### 29.2.2. Chart内の最小表示テキスト

実際のPowerPoint上では、以下のラベル・短文を中心に表示する。Supporting Logicの全文をスライド上へ掲載しない。

- Business Question
- キャンペーン投資を最適化したい
- Causal Question / Estimand
- 施策による購買の増分効果は何か
- Causal Design
- Treatment / Outcome / Confounders / Time
- Identification / Estimation

- Diagnostics / Sensitivity

- Decision / Action

## 29.3. Supporting Logic

- 単純な施策実施群と非実施群の差には、対象選定Biasが含まれる可能性がある。
- 施策割付の仕組みとPre-treatment情報を整理し、適切なIdentification Strategyを設計する。
- 平均効果だけでなく、業務上必要ならSegment別効果を評価する。
- 効果推定と診断・Sensitivityをセットで提示し、主張可能範囲を明示する。

- 補足論点：**因果推論は「施策実施群の成績が良い」から一歩進み、「施策によってどれだけ変わったか」を意思決定材料にする。**

## 29.4. Speaker Note

観測データで必ず因果効果が識別できるとは限らない。適用可否もPoCの重要な成果であると補足する。
