# 2. Slide 2｜データ分析で扱う3種類の問い

## 2.1. Message

**分析手法を選ぶ起点はアルゴリズムではなく、「何を知り、何を決めたいか」という問いの種類である。**

## 2.2. Chart

**チャートタイトル:** Business Questionと分析Familyの対応

Messageを説明・論証するための主たる視覚表現として、以下の構造を採用する。

### 2.2.1. Chart Structure

- 3列×4行（ヘッダー含む）の比較・整理表を主チャートとする。

| 業務上の問い | 主な分析観点 | 得られる情報 |
|---|---|---|
| 現状、何が起きているか | Exploratory | 分布・傾向・関係 |
| 今後、何が起こりそうか | Predictive | 未知・将来の予測 |
| 何をすると何が変わるか | Causal | 介入・施策の効果 |

**PowerPoint上の配置・強調**

- 3行×3列の比較チャートを中央に置く。
- PredictiveとCausalの2行を強調し、Exploratoryは前工程として控えめに示す。
- 各行は問い→分析→出力の順に読む構造とする。

### 2.2.2. Chart内の最小表示テキスト

| 業務上の問い | 主な分析観点 | 得られる情報 |
|---|---|---|
| 現状、何が起きているか | Exploratory | 分布・傾向・関係 |
| 今後、何が起こりそうか | Predictive | 未知・将来の予測 |
| 何をすると何が変わるか | Causal | 介入・施策の効果 |

## 2.3. Supporting Logic

- 探索・記述分析は、データの状態や関係を理解し、後続の問いを形成する。
- 予測分析は、観測された特徴から未知・将来のOutcomeを予測する。
- 因果推論は、Treatmentを変えた場合にOutcomeがどう変化するかを扱う。
- 当チームのPoCサービスはPredictive / Causalを中心とし、必要な探索・データ理解は両者の前工程として実施する。
- 補足論点：**「何が起きるか」と「何をすると変わるか」は異なる問いであり、同じデータでも必要な分析設計が変わる。**

## 2.4. Speaker Note

顧客に分析用語を覚えてもらうことが目的ではない。自分たちの問いがどのカテゴリーに属するかを直感的に判断できることを狙う。
