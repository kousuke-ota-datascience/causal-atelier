# A01-01. Appendix｜競争地位と顧客選択基準

## A01-01.1. Message

**競争地位は供給側、選択基準は顧客側の論理として分けて考える。**

## A01-01.2. Chart

**チャートタイトル:** Supplier-sideの競争戦略とCustomer-sideの選択基準

### A01-01.2.1. Chart Structure

上下2層の構造で示す。

上段はSupplier-side。

```text
競争地位
Leader / Challenger / Follower / Nicher
            ↓
Competitive Strategy
全方位 / 差別化 / 効率 / 集中
            ↓
Value Proposition / Signal
```

下段はCustomer-side。

```text
Customer Selection Criteria

Deal-specific Fit
Capability / Quality
Delivery Feasibility
Economic Value
Risk
Evidence / Credibility
Relational / Governance Fit
Organizational Acceptability
            ↓
Supplier Selection
```

中央に、Supplier側の強みはそのまま選択理由になるのではなく、**顧客側の評価軸に翻訳されて初めて選ばれる**ことを示す矢印を置く。

右側に4類型の典型的な「優位を作りやすい選択軸」を補助表示する。

| 競争地位 | 優位を作りやすい選択軸の例 |
|---|---|
| Leader | Evidence / Risk / Delivery / Organizational Acceptability |
| Challenger | Capability / Economics / Delivery / Specific Fit |
| Follower | Economics / Delivery / Risk |
| Nicher | Deal-specific Fit / Capability / Niche Evidence |

※一対一の固定対応ではなく、競争地位の特性から優位を作りやすい軸を示す仮説。

### A01-01.2.2. Chart内の最小表示テキスト

- Supplier-side：競争地位 → Competitive Strategy → Signal
- Customer-side：Selection Criteria → Supplier Selection
- **「Nicherだから選ばれる」のではなく、専門性がFit / Capability / Evidenceとして評価されて選ばれる**

## A01-01.3. Supporting Logic

### A01-01.3.1. 競争地位4類型の位置づけ

Kotler系の競争地位論では、Market Leader / Challenger / Follower / Nicherを市場内の競争地位として捉え、それぞれ異なる戦い方を想定する。

- Leader：市場拡大・シェア防衛・全方位
- Challenger：Leaderとの差別化・攻撃
- Follower：模倣・適応・効率
- Nicher：特定市場・顧客・課題への集中

これは**Supplier側の戦略分類**である。

### A01-01.3.2. 顧客選択基準との対応

一方、B2B顧客は、Professional Service / Industrial Buying研究で示されるように、単一基準ではなく複数の基準と複数StakeholderでSupplierを評価する。

本資料では、以下の8軸に統合している。

1. Deal-specific Fit
2. Capability / Quality
3. Delivery Feasibility
4. Economic Value
5. Risk
6. Evidence / Credibility
7. Relational / Governance Fit
8. Organizational Acceptability

重要なのは、競争地位と選択基準を同じレイヤで扱わないことである。

```text
SupplierのPositioning
        ↓
Strength / Value Proposition
        ↓
顧客に見えるSignal
        ↓
Customer Selection Criteriaで評価
        ↓
Supplier Selection
```

### A01-01.3.3. 当チームへの示唆

同一企業でもRelevant Marketによって競争地位は変わり得る。

例えば、

- 大手SIer全体としてはLeader / Challenger
- その中のデータ分析部門は分析市場で専門部隊
- さらにPredictive / Causal PoCではNiche specialist的Positioning

という多層構造があり得る。

この場合、

> **Enterprise VendorとしてのRisk / Delivery / Organizational Acceptabilityの基盤**
>
> ×
>
> **専門分析部門としてのFit / Capability**

を組み合わせられる可能性がある。

ただし、この組合せ自体が競争優位であることはEvidenceで確認する必要がある。

## A01-01.4. Speaker Note

競争地位の4類型と顧客の選択基準は、同じ分類ではありません。LeaderやNicherは企業側の戦い方の話です。一方、顧客はFit、Capability、Risk、実績、価格などの基準でVendorを評価します。

例えばNicherだから自動的に選ばれるわけではありません。狭い領域へ専門化することで、その顧客にとってProblem FitやCapability、関連実績が高まり、それが選択理由になります。

逆にLeaderは、必ずしも全案件で最高の専門性を持つ必要はありません。ブランド、豊富な実績、Delivery capacity、企業としての安心感などがEvidenceやRisk低減として評価されることがあります。

当チームを考える際も、SIerとしての基盤と分析専門部門としての専門性を分けた上で、顧客のどの選択基準へ効くかを見る必要があります。

## A01-01.5. Appendix A01-01からA01-02への接続

> ただし、顧客の選択基準は企業ごとに固定されているわけではない。同じ顧客でも、商談の内容によって重視する基準とBuying Centerは変わる。
