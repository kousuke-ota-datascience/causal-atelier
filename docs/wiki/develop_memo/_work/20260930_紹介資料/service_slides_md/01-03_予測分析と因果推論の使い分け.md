# 3. Slide 3｜予測分析と因果推論の使い分け

## 3.1. Message

**予測は「Outcomeを当てる」ため、因果は「介入によるOutcomeの変化を知る」ための分析であり、評価軸も前提も異なる。**

## 3.2. Chart

**チャートタイトル:** PredictiveとCausalの比較マトリクス

Messageを説明・論証するための主たる視覚表現として、以下の構造を採用する。

### 3.2.1. Chart Structure

- 3列×6行（ヘッダー含む）の比較・整理表を主チャートとする。

| 観点 | Predictive | Causal |
|---|---|---|
| 主な問い | 何が起こるか | 何をすると何が変わるか |
| 主対象 | Prediction | Intervention effect |
| 主な評価 | Out-of-sample性能 | 識別・推定・診断の妥当性 |
| 典型出力 | 予測値・確率 | ATE / ATT / CATE等 |
| 代表用途 | 優先順位・計画 | 施策選択・効果検証 |

**PowerPoint上の配置・強調**

- 左右2列の比較表を中心にする。
- 中央または下部に「Prediction ≠ Intervention Effect」を短く強調する。
- 数式を主役にせず、利用目的の差が一目で分かる構成とする。

## 3.3. Supporting Logic

- 高い予測精度は、ある変数を操作したときにOutcomeが変化することを保証しない。
- 因果推論では、どの因果効果を対象とするか、どの仮定で識別するかを明示する必要がある。
- 予測モデルのExplainabilityも、原則として因果効果そのものではない。
- 実務ではPredictiveとCausalを組み合わせ、対象抽出と施策選択を分担することもある。

- 補足論点：**「高い予測精度」と「正しい介入判断」は別問題であり、意思決定の種類に応じて分析を選ぶ。**
