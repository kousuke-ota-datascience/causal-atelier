# 13. Slide 13｜予測分析PoCの分析プロセス

## 13.1. Message

**予測PoCでは、モデル選定より先にPrediction Questionと検証設計を固定し、未知データで再現する性能を評価する。**

## 13.3. Supporting Logic

- Prediction Question：誰について、いつ時点で、何を、どの期間先まで予測するかを定義する。
- Target / Feature：予測時点で利用可能な情報だけを用い、Target leakageを防ぐ。
- Split Design：ランダム分割・時系列分割・Group分割等をデータ生成過程に合わせて選ぶ。
- Baseline：単純ルールや現行判断と比較し、モデル導入の増分価値を確認する。
- Holdout Evaluation：学習に使わないデータで性能を評価する。
- Error / Explainability：誤り方とモデル挙動を把握し、業務上危険な失敗モードを確認する。

- 補足論点：**「どのモデルを使うか」より、「どの時点の誰に対して性能を検証するか」の設計が予測PoCの成否を左右する。**

## 13.4. Speaker Note

予測PoCの典型的な失敗であるleakageと不適切なvalidationを意識した説明とする。
