# A01-01. Appendix｜競合各社の強みの源泉

## A01-01.1. Message

**主要Providerはいずれも広い対応力を持つ一方、競争力の源泉は異なる。**

## A01-01.2. Chart

**チャートタイトル:** 「できること」ではなく「何を強みに競うか」が異なる

### A01-01.2.1. Chart Structure

| Provider類型 | 競争力の源泉 | 顧客に伝わる代表的価値 |
|---|---|---|
| Consulting Analytics | Strategy / Transformation / Stakeholder Alignment | 経営課題から変革全体を設計できる |
| SIer Analytics | Integration / Security / Production / Operation | Enterprise環境で実装・運用までつなげられる |
| AI / Platform Vendor | Product / Standardization / Reuse / Scale | 既製Capabilityを速く展開・拡張できる |
| Data Science Specialist | Analytical Depth / Flexibility / Specialist Talent | 非定型な分析課題を専門的に扱える |
| **当チーム** | **Specialist Analytics × Enterprise Base** | **高度分析とEnterprise利用を同じPoCで考えられる** |

> 「でも、どの会社も分析から実装までできますよね？」

> **Capabilityの有無は重なる。違いは、どのCapabilityを主戦場として組み合わせているか。**

## A01-01.3. Supporting Logic

### A01-01.3.1. 「他社もできる」は正しい

大手Consulting Firm、SIer、Data Science専門会社、AI VendorはいずれもAnalytics / Engineering / Consulting / Integrationを広く提供し得る。従って競合比較を「できる / できない」で整理すると、ほぼ全社が重なる。

### A01-01.3.2. 差を見る単位はCapability Configuration

各Providerが、どのAssetへ継続投資し、どの人材を多く持ち、どの案件を繰り返し受注し、どのDelivery Modelを標準とするかによって、強みの源泉は異なる。

そのためCapability単体ではなく、**Capability Configuration / Operating Model / Positioning**として比較する。

### A01-01.3.3. 当チームの仮説

当チームはSIer内のAnalytics組織であり、Predictive / Causalの専門分析をScratch中心で提供する。

現時点のPositioning仮説は、

> **Data Science Specialist寄りのAnalytical Flexibility × SIerとしてのEnterprise Context**

である。

ただし、これが競争優位になるかは、顧客が何を基準に比較するか、また今回のDealでどの基準を重く見るかによって変わる。

### A01-01.3.4. 理論的背景

Supplier側のPositioningとCustomer側のSupplier Selectionは別レイヤである。Webster & Wind、Sheth等のOrganizational Buying研究では、顧客側の意思決定は複数基準・複数Stakeholderから構成される。

従って次頁では、Provider側ではなく**顧客側の比較基準**を定義する。

## A01-01.4. Speaker Note

各社ともかなり広いCapabilityを持っています。したがって「因果推論ができる」「Systemまで考えられる」といった単独Capabilityでは差はつきません。

違いは、何を本業として繰り返し提供し、どこへ人材・Asset・Delivery Modelを集中させているかです。当チームはSpecialist AnalyticsとEnterprise Baseの組合せをPositioning仮説としています。

ただし、その組合せが価値になるかは顧客の選び方次第です。次頁では、顧客がProviderを何の基準で比較するかを8軸で定義します。
