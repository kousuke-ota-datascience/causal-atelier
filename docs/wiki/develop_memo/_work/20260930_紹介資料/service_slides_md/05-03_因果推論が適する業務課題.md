# 19. Slide 19｜因果推論が適する業務課題

## 19.1. Message

**因果推論が適するのは、「施策を実施する／しない」「条件を変える／維持する」といった選択肢の効果を比較したい業務である。**

## 19.2. Chart

**チャートタイトル:** 代表的なCausal QuestionとDecision

Messageを説明・論証するための主たる視覚表現として、以下の構造を採用する。

### 19.2.1. Chart Structure

- 3列×6行（ヘッダー含む）の比較・整理表を主チャートとする。

| 業務領域 | Causal Question | Decision |
|---|---|---|
| マーケティング | キャンペーンで購買は増えるか | 施策継続・配分 |

## 19.3. Supporting Logic

- Treatmentが明確で、Outcomeと対象Populationを定義できる課題が候補となる。
- A/B Testが可能なら実験を優先できるが、安全・コスト・倫理・時間等の理由で観測データ分析が必要な場合がある。
- 観測データで十分なPre-treatment covariatesや時間構造を持たない場合、識別困難となる可能性がある。
- 「原因を知りたい」という曖昧な問いは、具体的なTreatmentとEstimandへ落とす必要がある。

- 補足論点：**因果推論の入口は「原因探索」ではなく、比較したい介入・対象・Outcomeを明確にしたCausal Questionである。**

## 19.4. Speaker Note

「因果推論を使えば何でも原因が分かる」という期待を抑制し、明確な介入問いがある案件に向くことを示す。
