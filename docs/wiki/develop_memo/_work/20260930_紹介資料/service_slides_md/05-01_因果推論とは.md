# 18. Slide 18｜因果推論とは

## 18.1. Message

**因果推論は、観測された関連ではなく「Treatmentを変えたときOutcomeがどう変わるか」という反実仮想の問いを扱う。**

## 18.2. Chart

**チャートタイトル:** Observationでは見えない「もう一方の結果」を推論する

### 18.2.1. Chart Structure

Customer Retentionを最小例として、左から右へ3段階で示す。

```text
① Observation
Retention施策あり群   解約率 低
Retention施策なし群   解約率 高
        ↓
この差だけでは施策効果とは言えない
        ↓
② Counterfactual Question
同じ対象に対して
施策あり / なしを切り替えたら
解約はどれだけ変わるか？
        ↓
③ Causal Effect
Y(1) - Y(0)
ただし同じ対象の両方は同時に観測できない
→ 比較可能性を作るDesign / Assumptionが必要
```

**PowerPoint上の配置・強調**

- 左：観測された群間差。
- 中央：同一対象の2つのPotential Outcomeを上下に置き、片方が未観測であることを視覚化する。
- 右：`Treatment Effect = Counterfactual Difference` を置く。
- 数式は `Y(1) - Y(0)` 程度に留める。
- 最下部に `観測差 ≠ 因果効果` を短く置く。

### 18.2.2. Chart内の最小表示テキスト

- Observation｜施策あり群となし群で結果が違う
- **観測差 ≠ 因果効果**
- Counterfactual｜同じ対象で施策あり / なしなら？
- `Y(1)` / `Y(0)`
- **Treatment Effect = Y(1) - Y(0)**
- 両方は同時に観測できない
- Design / Assumptionで比較可能性を作る

## 18.3. Supporting Logic

- 因果推論の対象は、単なるAssociationではなくTreatmentを操作したときのOutcome変化である。
- Potential Outcomesの枠組みでは、各UnitについてTreatment状態ごとのOutcomeを考えるが、実際に観測できるのは一つだけである。これがFundamental Problem of Causal Inferenceである。
- RCTではRandomizationにより群間の比較可能性を設計する。観測データでは、目的のEstimandに応じた追加のIdentification Assumptionが必要になる。
- 出力は「因果あり / なし」という一般論ではなく、Population・Treatment・Outcome・Contrast等で定義したEffect Estimateである。
- 高度な予測モデルや相関分析を用いても、それだけではCounterfactual Comparisonは得られない。

## 18.4. Speaker Note

ここで区別したいのは、観測された差と、施策によって生じた差です。たとえばRetention施策を受けた顧客の解約率が低くても、もともと解約しにくい顧客へ施策を出していた可能性があります。

因果推論が知りたいのは、同じ対象に施策を行った場合と行わなかった場合で、Outcomeがどれだけ変わるかです。ただし同じ対象の両方の結果は同時には観測できません。そのため、実験や観測データ上の仮定を使って、妥当な比較対象を作る設計が必要になります。
