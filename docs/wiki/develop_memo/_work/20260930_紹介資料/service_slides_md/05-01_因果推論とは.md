# 17. Slide 17｜因果推論とは

## 17.1. Message

**因果推論は、観測された関連ではなく「Treatmentを変えたときOutcomeがどう変わるか」という反実仮想の問いを扱う。**

## 17.2. Chart

**チャートタイトル:** ObservationとInterventionの違い

Messageを説明・論証するための主たる視覚表現として、以下の構造を採用する。

### 17.2.1. Chart Structure

- 既存の論理フロー／概念図を主チャートとして用い、要素間の関係・順序が一目で追える構造にする。

```text
Observation
Tが異なる群でYが違う
        ↓
「関連がある」

Intervention / Counterfactual
同じ対象で T=1 と T=0 を比べたら
Yはどれだけ変わるか
        ↓
「因果効果」
```

**PowerPoint上の配置・強調**

- ObservationとInterventionを上下または左右に対比する。
- Counterfactualの概念をシンプルな2状態の図で示す。
- 数式は補助的にし、概念理解を優先する。

### 17.2.2. Chart内の最小表示テキスト

実際のPowerPoint上では、以下のラベル・短文を中心に表示する。Supporting Logicの全文をスライド上へ掲載しない。

- Observation
- Tが異なる群でYが違う
- 「関連がある」
- Intervention / Counterfactual
- 同じ対象で T=1 と T=0 を比べたら
- Yはどれだけ変わるか
- 「因果効果」

## 17.3. Supporting Logic

- 因果効果は、同じ対象について複数のTreatment状態を同時に観測できないというFundamental Problemを持つ。
- RCTでは無作為化により比較可能性を作る。観測データでは追加の識別仮定が必要となる。
- 因果推論の出力は単一の「因果あり／なし」ではなく、対象PopulationやEstimandに依存するEffect Estimateである。
- 結果は仮定・データ・診断結果と一体で解釈する。

- 補足論点：**相関を高度なモデルで分析しても自動的に因果にはならず、介入効果を識別するための設計が必要である。**

## 17.4. Speaker Note

因果推論を「AIが原因を発見する技術」と誤解させない。反実仮想と識別仮定が本質である。
