# 15. Slide 15｜予測モデルの評価と解釈

## 15.1. Message

**予測モデルは単一のAccuracyで評価せず、未知データ性能・Calibration・失敗パターン・業務コストを組み合わせて判断する。**

## 15.2. Chart

**チャートタイトル:** Predictive Evaluationの4層

Messageを説明・論証するための主たる視覚表現として、以下の構造を採用する。

### 15.2.1. Chart Structure

- 既存の論理フロー／概念図を主チャートとして用い、要素間の関係・順序が一目で追える構造にする。

```text
① Discrimination / Error
AUROC・AUPRC・MAE・RMSE 等
        ↓
② Calibration
予測確率と実発生率の整合
        ↓
③ Segment / Error Analysis
どこで失敗するか
        ↓
④ Business Utility
閾値・誤判定コスト・Action価値
```

**PowerPoint上の配置・強調**

- 4層の縦積みピラミッドまたは階段図とする。
- 上から統計評価→業務評価へ進む構造を明確にする。
- 指標一覧を詰め込み過ぎず、代表例だけ表示する。

### 15.2.2. Chart内の最小表示テキスト

実際のPowerPoint上では、以下のラベル・短文を中心に表示する。Supporting Logicの全文をスライド上へ掲載しない。

- ① Discrimination / Error
- AUROC・AUPRC・MAE・RMSE 等
- ② Calibration
- 予測確率と実発生率の整合
- ③ Segment / Error Analysis
- どこで失敗するか
- ④ Business Utility
- 閾値・誤判定コスト・Action価値

## 15.3. Supporting Logic

- 分類ではAUROC、AUPRC、Precision / Recall等を目的に応じて使い分ける。
- 回帰ではMAE、RMSE等を業務上の誤差許容度と対応付ける。
- 確率を意思決定に使う場合はCalibrationが重要となる。
- 全体平均だけでなく、重要Segmentや期間別に性能劣化を確認する。
- SHAP等のExplainabilityはモデル挙動理解に用いるが、因果効果として解釈しない。

- 補足論点：**モデル評価の最終単位は統計指標ではなく、「その誤り方を許容して業務Actionに使えるか」である。**

## 15.4. Speaker Note

Accuracy偏重を避ける。特にclass imbalanceや閾値依存の業務ではPrecision / RecallやCalibrationが重要になることを補足する。
