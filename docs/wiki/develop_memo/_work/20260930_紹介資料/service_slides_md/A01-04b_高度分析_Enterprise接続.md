## A01-04b.3. Supporting Logic

### A01-04b.3.1. なぜこの6軸Profileなのか

この類型は、具体的なOperational〜Business Decisionを対象に、高度なPredictive / Causal / Experimental分析を個別設計し、その成果を将来のEnterprise利用へ接続する案件を表す。

Decision AltitudeはOperational〜Businessとする。Corporate Transformation全体ではなく、Churn、Demand、Risk、Treatment Effect等の具体的Decision Problemを主対象とするためである。

Problem NoveltyとAnalytical ComplexityはMedium〜High / High。Outcome / Treatment / Assumption / Evaluation等を案件固有に設計する必要がある。

Implementation CouplingとCriticalityはHigh / Medium〜High。PoC後のData pipeline、System Integration、Security、Operation、Governanceを無視できないためである。

### A01-04b.3.2. なぜこのSelection Weightになるのか

B2B購買ではBuying Situation、Buying Center、Perceived Riskによって評価基準が変化する。[T1][T2][T3]

本Profileでは分析品質に加えて、実装・運用上の失敗リスクも重要になるため、Deal-specific Fit / Capability / Delivery / Risk / Evidence / Organizational AcceptabilityをHighと置く。

Professional ServiceでQuality Signalが重要になること、Implementation Couplingが高い取引でdependencyやadaptationが問題になることは、Professional Service Selection研究とTCEを理論的背景とする。[T4][T5][T6][T7]

### A01-04b.3.3. Consulting AnalyticsのPosition

DeloitteやAccentureはStrategyだけでなく、AI / Data / Engineering / bespoke solution / scaleまで提供する。[P2][P3]

従って、高度分析とEnterprise接続を両方求める本ProfileでStrong Candidateになり得る。特にDecision Altitudeが上がり、Transformation / Stakeholder AlignmentまでScopeが広がると有利になりやすい。

### A01-04b.3.4. SIer AnalyticsのPosition

NTT DATA等のSIer AnalyticsはAI Consulting、PoC、Model Training、Application Integration等を一連で提供している。[P4]

Implementation Coupling、Security、Production、Organizational Acceptabilityが重い本Profileでは構造的にStrong Candidateとなる。ただしAnalytical Complexityが高いほど、Methodological CapabilityとRelevant Evidenceが勝敗を左右する。

### A01-04b.3.5. DS SpecialistのPosition

DS Specialistは高度分析では強いが、Implementation Couplingが高まるとSecurity / Architecture / Production / Governanceまで評価対象になる。[P1]

これらを自社またはPartnerで十分に提供できる会社もあるため「Enterpriseに弱い」とは一般化せず、Competitiveとする。

### A01-04b.3.6. AI / Platform VendorのPosition

Palantir等はData / Model / Workflow / Operational Applicationを統合するEnterprise Assetを持つ。[P5]

顧客ProblemがProduct Capabilityへ高くFitする場合は強い。一方、Question / Estimand / Evaluationが高度に個別化されるほどProduct Assetの優位が小さくなり得るため、Product Fit依存とする。

### A01-04b.3.7. 当チームのPosition

当チームの確認済みCapabilityは、Predictive / Causal、Scratch + OSS、Question / Assumption / Evaluation設計、特定Product非必須、SIer内Analytics組織である。

本Profileでは、

- Analytical Complexity / Novelty → Specialist Analytics
- Implementation Coupling / Criticality → Enterprise Base

の双方が同時にCustomer Selection Criteriaへ接続する。

従って、

> **Core Candidate。ただしRelative Advantageは未証明。**

とする。

### A01-04b.3.8. Relative Advantageの有無

この領域は競合空白地帯ではない。他SIer Analytics、Consulting Analytics、Enterprise対応可能なDS Specialist、Product Fitの高いPlatform Vendorが競合し得る。

Competitive Gapを確認するには、Methodological Expertise、Specialist Direct Access、Enterprise連携、本番化実績、Price / Lead Time、顧客選定理由を同一Deal条件で比較する必要がある。

### A01-04b.3.9. 反証条件

- 他SIer Analyticsが同等以上のPredictive / Causal専門性を持ち、Delivery / Priceでも優位
- Consulting Analyticsが同等以上のHands-on分析をより高いBusiness Fitとともに提供
- DS SpecialistがEnterprise Integrationまで一貫して持ち、Relevant Evidenceで優位
- AI Platformが顧客課題へ高くFitし、Custom PoCより短期・低コスト

### A01-04b.3.10. Evidence / Inference区分

**Published Evidence:** B2B購買の状況依存性、Professional ServiceのQuality Signal、TCEのAsset Specificity / Uncertainty。[T1]〜[T7]

**Provider一次情報:** BrainPad、Deloitte、Accenture、NTT DATA、PalantirのOffering。[P1]〜[P5]

**当資料の分析仮説:** 本6軸Profile、8軸Weight、当チーム＝Core Candidate、SIer / Consulting＝Strong CandidateというPositioning。学術研究が順位を直接実証したものではない。

## A01-04b.4. Speaker Note

このProfileは当チームの重点候補です。高度分析だけでなく、その結果をEnterprise環境で使う条件まで同時に問われるため、Specialist AnalyticsとEnterprise Baseの両側が評価されます。

ただし空白地帯ではありません。SIerやConsultingも広いCapabilityを持つため、ここで本当に選ばれるかは実績、人材、価格、Lead Time等のEvidenceで確認します。

## A01-04b.5. A01-04への示唆

> A01-04bは当チームのCapability Bundleが最も全面的に効くAnchorの一つであり、A01-04無印の重点Positioningを支える中核ロジックとなる。
