## 1.3. Supporting Logic

### 1.3.1. 予測分析と因果推論の論理構造

| | 予測分析 | 因果推論 |
|---|---|---|
| 問い | **何が起こりそうか？** | **何をするとどう変わるか？** |
| 得られる情報 | 将来・未知のOutcomeの予測 | 施策・介入によるOutcomeの変化 |
| 意思決定への価値 | **将来を見越して判断できる** | **施策の効果を踏まえて判断できる** |
| 例 | 機材の稼働予測 → 保守・点検対象を決める | 施策効果推定 → 施策実施を決める |

- 予測分析と因果推論はいずれも、分析結果を業務上の意思決定に利用するための分析である。
- 両者の違いは「意思決定につながるか」ではなく、意思決定に提供する情報の種類にある。
- 予測分析は将来・未知のOutcomeに関する見通しを提供し、計画、資源配分、対象の優先順位付け等の判断に利用する。
- 因果推論は施策・介入によるOutcomeの変化を判断材料として提供し、施策の実施、継続、変更等の判断に利用する。

### 1.3.2. 予測分析

- 予測分析は、現在までに観測できる情報を用いて、未知・将来のOutcomeを予測する。
- 顧客にとっての価値は、将来の状態に関する不確実性を減らし、その見通しを現在の計画・配分・優先順位等の判断材料として利用できることである。
- 例えば機材の稼働状態や停止リスクを予測できれば、その見通しを基に、保守・点検の対象や時期、要員配置等を判断できる。
- 予測できることと、その要因へ介入すればOutcomeを変えられることは別であり、予測結果やPredictive Explainabilityを因果効果として解釈しない。

### 1.3.3. 因果推論

- 因果推論は、単なる変数間の関連ではなく、施策・介入を変えたときにOutcomeがどの程度変化するかを扱う。
- 顧客にとっての主要な価値は、施策・介入によるOutcomeの変化を推定し、その効果を施策の実施・継続・変更等の判断材料として利用できることである。
- 例えば施策効果の評価であれば、「施策を実施したことでOutcomeがどの程度変わるか」を検討し、施策を実施・継続するかという判断に利用できる。
- 因果推論では、効果推定に必要な因果構造、比較条件、Identification Assumption等を明示するため、Effect Estimateだけでなく「どの前提のもとで、なぜその効果を主張できるのか」を説明可能な形で整理できる。
- ここでいう説明性はPredictive Explainabilityとは異なる。Feature importance、SHAP等は予測モデルの振る舞いを説明するものであり、変数への介入効果を意味しない。
- また、因果構造そのものがデータから自動的に確定するわけではなく、ドメイン知識、時間順序、データ生成過程、実験・制度設計等に基づく仮定を含む。

### 1.3.4. 両サービスに共通する提供価値

- 当チームが提供するPoCでは、モデルやEffect Estimateを作成すること自体を最終目的とせず、分析結果を顧客のDecision / Actionに利用できる判断材料へ接続することを重視する。
- Slide 1では、この共通価値を「将来の見通し」と「施策効果」という2種類の判断材料として提示する。
- 売上向上、コスト削減、ROI改善等のBusiness Outcomeは、分析結果を受けて実際のActionが変わった先に生じる可能性のある効果であり、本スライドで分析サービスの直接的成果として保証しない。
- 分析結果からDecision / Action、Business Outcomeへどのようにつながるかの詳細は、01-04「分析サービス適用による期待効果」で説明する。
- 当チーム固有の強み、分析設計能力、実装方針等の「なぜ当チームに依頼するのか」という論点は、01-05で独立して説明する。

## 1.4. Speaker Note

当チームでは、大きく予測分析と因果推論の2種類のPoCをご支援しています。

予測分析が答えるのは、「何が起こりそうか」という問いです。例えば機材の稼働状態や停止リスクを予測できれば、その見通しをもとに保守・点検の対象や時期、要員配置を判断できます。つまり、将来の見通しを業務の判断材料にするための分析です。

一方、因果推論が答えるのは、「何をするとどう変わるか」という問いです。例えば、ある施策を実施したことで成果がどの程度変わるのかを推定し、その結果を施策の実施や継続の判断材料にします。

ここで重要なのは、予測分析と因果推論のどちらも業務上の意思決定につながるという点です。違いは、意思決定に使う情報の種類です。予測分析は「将来の見通し」を、因果推論は「施策の効果」を判断材料として提供します。

また、予測できることと、何かに介入すれば結果を変えられることは同じではありません。そのため、何を知り、何を決めたいのかに応じて、予測分析と因果推論を適切に使い分ける必要があります。
