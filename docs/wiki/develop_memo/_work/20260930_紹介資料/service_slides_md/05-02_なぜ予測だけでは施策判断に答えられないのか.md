# 18. Slide 18｜なぜ予測だけでは施策判断に答えられないのか

## 18.1. Message

**「結果が悪くなりそうな対象」と「施策によって結果を改善できる対象」は一致しないため、施策判断には因果効果が必要になる。**

## 18.2. Chart

**チャートタイトル:** Risk PredictionとTreatment Effectの2×2

Messageを説明・論証するための主たる視覚表現として、以下の構造を採用する。

### 18.2.1. Chart Structure

- 3列×3行（ヘッダー含む）の比較・整理表を主チャートとする。

|  | 施策効果 小 | 施策効果 大 |
|---|---|---|
| リスク 低 | 優先度低 | 改善余地あり |
| リスク 高 | 高リスクだが効かない | **最優先候補** |

**PowerPoint上の配置・強調**

- 2×2マトリクスを中央に置き、右下を強調する。
- 横軸をTreatment Effect、縦軸をBaseline Riskとする。
- 具体的な顧客名や数値は置かない。

### 18.2.2. Chart内の最小表示テキスト

実際のPowerPoint上では、以下のラベル・短文を中心に表示する。Supporting Logicの全文をスライド上へ掲載しない。

|  | 施策効果 小 | 施策効果 大 |
|---|---|---|
| リスク 低 | 優先度低 | 改善余地あり |
| リスク 高 | 高リスクだが効かない | **最優先候補** |

## 18.3. Supporting Logic

- 解約確率が高い顧客でも、キャンペーンに反応しないなら施策対象として効率的とは限らない。
- 逆に現状リスクが中程度でも、施策効果が大きい対象は投資価値が高い可能性がある。
- 予測モデルはOutcomeの条件付き分布を捉えるが、Treatmentを操作した際の差を直接保証しない。
- 業務課題が「誰が起こすか」ではなく「誰に何をすべきか」であれば、因果的な問いへ変換する。

- 補足論点：**ターゲティングではRiskだけでなくIncremental Effectを見ることで、施策が効く対象へ資源を配分できる。**
