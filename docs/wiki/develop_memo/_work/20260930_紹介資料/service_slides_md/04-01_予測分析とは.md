# 10. Slide 10｜予測分析とは

## 10.1. Message

**予測分析は、観測済みの情報から未知・将来のOutcomeを推定し、事前に判断や資源配分を変えるための分析である。**

## 10.2. Chart

**チャートタイトル:** Predictive Analyticsの基本構造

Messageを説明・論証するための主たる視覚表現として、以下の構造を採用する。

### 10.2.1. Chart Structure

- 既存の論理フロー／概念図を主チャートとして用い、要素間の関係・順序が一目で追える構造にする。

```text
現在までに分かっている情報 X
          ↓
     Predictive Model
          ↓
未知・将来のOutcome Ŷ / Probability
          ↓
優先順位・計画・警告・資源配分
```

**PowerPoint上の配置・強調**

- X→Model→Prediction→Decisionの4段階を横並びにする。
- Modelの箱を過度に強調せず、PredictionとDecisionを同程度以上に見せる。
- アルゴリズム一覧は後続へ分離する。

### 10.2.2. Chart内の最小表示テキスト

実際のPowerPoint上では、以下のラベル・短文を中心に表示する。Supporting Logicの全文をスライド上へ掲載しない。

- 現在までに分かっている情報 X
- Predictive Model
- 未知・将来のOutcome Ŷ / Probability
- 優先順位・計画・警告・資源配分

## 10.3. Supporting Logic

- Classification：解約・故障・不正などの発生確率やクラスを予測する。
- Regression：売上・需要・工数・損失額等の連続値を予測する。
- Forecasting：時間依存構造を持つ需要・負荷等の将来値を予測する。
- 主な評価対象は未知データに対する汎化性能であり、学習データへの当てはまりだけでは判断しない。

**旧Key Messageから保持する補足論点**

> **予測分析の目的は未来を完全に当てることではなく、不確実性のある未来について事前の意思決定を改善することである。**

> この補足はMessageとは別の第二メッセージとして扱わず、Messageを支える論点としてのみ使用する。

## 10.4. Speaker Note

予測モデル自体は手段であることを最初に明確にする。特にProbability出力が意思決定閾値に使われる点を後続へつなぐ。
