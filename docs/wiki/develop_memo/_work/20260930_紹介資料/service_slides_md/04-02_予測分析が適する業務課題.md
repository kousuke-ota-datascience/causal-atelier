# 11. Slide 11｜予測分析が適する業務課題

## 11.1. Message

**予測分析が特に有効なのは、結果が起きる前に予測を使って対象・時期・量を変えられる業務である。**

## 11.2. Chart

**チャートタイトル:** 予測ユースケースを「予測→Action」で整理する

Messageを説明・論証するための主たる視覚表現として、以下の構造を採用する。

### 11.2.1. Chart Structure

| 予測対象 | 代表的な予測 | 予測後のAction |
|---|---|---|
| 顧客 | 解約・成約確率 | フォロー対象を優先 |
| 需要 | 商品・サービス需要 | 在庫・要員を調整 |
| 設備 | 故障・異常確率 | 点検・保全を前倒し |
| 取引 | 不正・信用リスク | 審査・監視を強化 |

- 右端のAction列を強調し、予測だけで終わらないことを示す。

## 11.3. Supporting Logic

- 「予測できるか」だけでなく「予測後に行動を変えられるか」が適用価値を左右する。
- 予測時点より後の情報がFeatureに混入しないよう、業務上の利用時点を明確にする。
- 対象母集団や予測頻度が不明確な場合、モデル精度が高くても運用設計が成立しにくい。
- ユースケース選定時には誤検知・見逃しの業務コストも確認する。
- 補足論点：**予測の適用可否は、予測精度だけでなく「事前にActionを変えられる業務構造」があるかで決まる。**

## 11.4. Speaker Note

具体的な業界例を挙げつつ、どの例もPredictionが業務Actionへ接続している点を強調する。
