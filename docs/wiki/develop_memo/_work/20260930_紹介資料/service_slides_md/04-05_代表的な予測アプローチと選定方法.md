# 14. Slide 14｜代表的な予測アプローチと選定方法

## 14.1. Message

**予測モデルは一律に高度な手法を選ぶのではなく、データ特性・必要性能・説明性・運用制約のバランスで選定する。**

## 14.3. Supporting Logic

- 代表候補としてLinear / Logistic Regression、Tree-based Model、Random Forest、Gradient Boosting、時系列モデル等を検討する。
- 単純なモデルをBaselineとして持つことで、複雑化による増分価値を判断できる。
- モデル選定は単一指標最大化だけでなく、Calibration、安定性、解釈性、推論コスト等も考慮する。
- 必要に応じてハイパーパラメータ探索を行うが、検証データへの過適合を避ける。

- 補足論点：**「最も複雑なモデル」ではなく、「意思決定に必要な性能と運用条件を満たすモデル」を選ぶ。**
