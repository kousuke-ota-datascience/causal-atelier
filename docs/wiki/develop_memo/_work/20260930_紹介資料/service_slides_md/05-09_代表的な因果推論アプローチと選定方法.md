# 26. Slide 26｜代表的な因果推論アプローチと選定方法

## 26.1. Message

**因果推論は手法名から選ぶのではなく、Treatmentの割付・時間・制度・交絡情報からIdentification Strategyを選定する。**

## 26.2. Chart

**チャートタイトル:** Data Generating ProcessからIdentification Strategyを選ぶ

### 26.2.1. Chart Structure

「データ・制度上の構造 → Identificationの考え方 → 主なAssumption」を主表とし、Estimator例は別列へ分離する。

| データ・制度上の構造 | Identification Strategy | 主なAssumption / 成立条件 | Estimation例 |
|---|---|---|---|
| Randomized Assignmentが可能 | Randomized Comparison / RCT / A-B Test | Randomization、Consistency等 | 群平均差、Regression等 |
| 必要なPre-treatment Confounderを観測 | Backdoor / Covariate Adjustment | Conditional Exchangeability、Positivity、Consistency | G-formula / Regression、Weighting、Matching、DR |
| Treatment前後 + 比較群がある | Difference-in-Differences | Parallel Trends等 | DiD Estimator / Regression等 |
| AssignmentがThresholdで決まる | Regression Discontinuity | 閾値近傍のContinuity、Manipulationがない等 | Local Regression等 |
| Valid Instrumentがある | Instrumental Variable | Relevance、Independence、Exclusion等 | Wald / 2SLS等 |
| Single Treated Unit + Donor Pool + Time | Synthetic Control | 適切なCounterfactualをDonorから構成可能等 | Synthetic Control Estimation |

**PowerPoint上の配置・強調**

- 左から `Data / Assignment` → `Identification Strategy` → `Assumption` の3列を主表示とする。
- Estimation例は右端の細い補助列にし、前Slideで示したIdentification / Estimationの責務分離を崩さない。
- 「交絡を十分観測」の行では `Backdoor / Covariate Adjustment` をIdentification側に置き、Regression / Weighting / Matching / DRはEstimation側に置く。
- 手法数を増やすことを目的にせず、代表的なData Generating Processの違いを示す。
- 各行でAssumption列を必ず見せ、「○○法を使えば因果になる」という読み方を防ぐ。

| Data / Assignment | Identification | Assumption |
|---|---|---|
| Randomized | RCT / A-B | Randomization |
| Confounder観測 | Covariate Adjustment | Exchangeability / Positivity |
| 前後 + 比較群 | DiD | Parallel Trends |

- Estimation例：Regression / Weighting / Matching / DR 等
- **Strategyを選んでからEstimatorを選ぶ**

## 26.3. Supporting Logic

- RCT / A-B TestはRandomized AssignmentによってTreatment群とControl群の比較可能性を設計する有力なApproachである。ただしNoncompliance、Attrition、Interference、Outcome Measurement等の論点は別途確認する。
- Observational DataでBackdoor Adjustmentを用いる場合、対象Estimandに必要なPre-treatment Confounderが観測されていること、条件付きExchangeability、Positivity、Consistency等が重要になる。これらは単にCovariate数を増やせば成立するものではない。
- Difference-in-DifferencesはTreatment前後と比較群の構造を利用するが、Parallel Trends等のAssumptionが必要である。Pre-trendは有用なDiagnosticになり得るが、将来のParallel Trendsを証明するものではない。
- Regression DiscontinuityはThreshold周辺のAssignment構造を利用し、一般にThreshold近傍のLocal Effectを対象とする。適用範囲をPopulation全体へ無条件に外挿しない。
- Instrumental VariableはInstrumentがTreatmentへ影響し、OutcomeへTreatment以外の経路で影響しない等の強いAssumptionを必要とする。解釈するEstimandも条件に依存する。
- Synthetic Controlは単一または少数のTreated Unitに対しDonor PoolからCounterfactual Trajectoryを構成する代表的Approachであり、Pre-treatment FitやDonor構成等を確認する。
- Causal ML / Meta-learner / Causal Forest等は、特にHeterogeneous Treatment EffectのEstimationで候補になり得るが、Identification Assumptionを不要にはしない。
- 実務上は「Method名にDataを当てはめる」のではなく、Treatment Assignment Mechanism、Temporal Structure、Policy / Rule、観測可能なConfounder等から、どの識別論理が妥当かを先に判断する。

## 26.4. Speaker Note

因果推論の手法は、精度ランキングのように一列に並べて選ぶものではありません。Treatmentがランダムに割り付けられるのか、必要な交絡要因を観測できるのか、前後比較と対照群があるのか、閾値や制度上の割付ルールがあるのかによって、利用できるIdentification Strategyが変わります。

また、各Strategyには成立条件があります。たとえば観測データでCovariate Adjustmentを使う場合でも、必要な交絡要因が観測されていることなどが前提です。その識別論理を定めた後で、RegressionやWeightingなど、有限標本から推定する方法を選びます。

## 26.5. Slide 26からSlide 27への接続

> **Identification StrategyとEstimatorを定めてEffectを推定しても、それだけではPoCは完了しない。最後に、設計に応じたDiagnosticsとSensitivityを含むEvidence Stackから、どこまで主張できるかを判断する。**
