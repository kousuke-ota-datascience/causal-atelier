# 25. Slide 25｜代表的な因果推論アプローチと選定方法

## 25.1. Message

**因果推論の手法は、利用できる実験・制度・時間構造・交絡情報に応じてIdentification Strategyから選定する。**

## 25.3. Supporting Logic

- 実験可能なら、倫理・運用制約を踏まえつつRCTを第一候補として検討できる。
- 観測研究では、仮定がデータや業務知識と整合するかを先に確認する。
- 手法名が同じでも対象Population、Treatment timing、Outcome window等で設計は大きく変わる。
- Causal MLは異質効果推定等に有用だが、識別仮定を不要にするものではない。

- 補足論点：**手法から問いを当てはめるのではなく、問いとデータ生成過程から識別戦略を選び、その後に推定法を決める。**
