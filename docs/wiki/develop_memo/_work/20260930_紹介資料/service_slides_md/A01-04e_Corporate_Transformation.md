## A01-04e.3. Supporting Logic

### A01-04e.3.1. このProfileでは「分析」以外が購買対象の中心になる

このProfileの典型は、

- 全社AI / Data Strategy
- Business Transformation
- Target Operating Model
- AI投資Portfolio設計
- Organization / Process Change
- Executive-level governance

等である。

分析は重要な構成要素になり得るが、顧客が買うものは個別Modelや推定結果ではなく、**複数部門をまたぐ意思決定・変革設計・実行Governance**である。

Webster & WindはOrganizational BuyingをBuying Centerを含む組織的意思決定として扱う。[T1] Shethも購買関係者ごとに異なるExpectationが存在し、Joint Decisionが生じることをモデル化した。[T2]

Decision Altitudeが高いほどExecutive / Business / IT / Procurement等のStakeholderが増え、技術Capabilityだけでなく、Evidence / Relationship / Governance / Organizational Acceptabilityが重要になりやすい、というのが本資料の分析仮説である。

### A01-04e.3.2. Consulting AnalyticsをStrong Candidateとする根拠

DeloitteのAI & Data OfferingはAI Strategy、Data Modernization、AI Engineering等を含み、Technology単体ではなくEnterprise Transformationを射程に置く。[P2]

AccentureもData & AIをStrategy / Reinvention / Build / Scaleの文脈で提供している。[P3]

つまり大手Consulting Analyticsは、

- Executive-level Strategy
- Business / Operating Model
- Cross-functional governance
- Technology / Analytics
- Change / Scale

を一つのOfferingとして組み合わせられる。

このため、Corporate / Transformation Profileでは構造的にStrong Candidateと置く。

### A01-04e.3.3. SIer AnalyticsがCompetitiveとなる理由

TransformationがEnterprise Architecture / Cloud / Core System Refresh等と強く結びつく場合、SIerも強いCandidateになる。NTT DATAはAI Strategy / Roadmap / PoC / Integrationまでを公式に提供する。[P4]

ただし、案件価値の中心がExecutive Alignment / Operating Model / Organization Changeにある場合、そのCapabilityの深さは個社・部門差が大きい。

### A01-04e.3.4. DS SpecialistをWorkstream Candidateとする理由

DS SpecialistはAnalytical Workstream、Use Case検証、Model / Causal Analysis等では重要な役割を持ち得る。[P1]

しかしPrime Contractorとして案件全体を評価する場合、顧客は、

- Executive facilitation
- Transformation governance
- Cross-business coordination
- Program delivery

まで要求する可能性がある。

従って「分析が強い」だけでは案件全体のDeal-specific Fitにならず、Analytical WorkstreamでのCandidateと整理する。

### A01-04e.3.5. AI / Platform Vendorの位置づけ

Platform VendorがTransformationのAnchorになる場合はある。PalantirのようにOperational ApplicationやOntologyを中心に業務Processを再設計するProviderも存在する。[P5]

ただし、Vendor-neutralなStrategy、Organization Design、複数Technologyを跨ぐRoadmapが購買対象なら、特定Platform起点のFitは下がる可能性がある。

### A01-04e.3.6. 当チームのFit

当チームは、

- Predictive / Causal PoC
- Scratch / OSS
- Question / Assumption / Evaluation設計
- Enterprise Context

を持つため、具体的なAnalytical WorkstreamではFitし得る。

一方、現時点で確認できていないのは、

- Enterprise-wide Transformation Strategyの実績
- Executive Facilitation
- Organization / Operating Model Design
- Large Program Governance

である。

従って、案件全体のPrime Positionとしては、

> **Relative Weak〜Competitive。Analytical WorkstreamではCompetitive。**

とする。

### A01-04e.3.7. Evidence / Credibilityが特に重要になる理由

Professional Serviceでは購入前に品質を直接評価しにくいため、顧客はReputation / Experience / Resource Quality等のSignalを用いる。[T4][T5]

Corporate Transformationは失敗時の影響が大きく、複数Stakeholderの合意が必要である。このため、

- 類似Transformation実績
- Executive-facing team
- Reputation
- Industry experience

が強いSignalになり得る。

当チームにこのEvidenceが乏しいなら、分析Capabilityが高くてもPrime Vendorとして選ばれる理由は弱い。

### A01-04e.3.8. 反証条件 / Positionを上げる条件

以下が確認されれば、当チームPositionは上げ得る。

- 全社 / 事業Transformationの主契約実績
- Executive stakeholderを巻き込んだAI / Analytics Strategy実績
- Parent SIerのConsulting Capabilityを当チームが一体利用できるDelivery Model
- StrategyからAnalytical PoCまで一貫した競合勝ち実績

逆にこれらがなければ、本ProfileをWhy Usの中心には置かない。

### A01-04e.3.9. Evidence / Inferenceの区分

**Published Evidence**
- B2B購買はBuying Center / Joint Decision / 複数評価基準で構成される。[T1][T2]
- Professional ServiceではReputation / Experience / Quality Signalが重要。[T4][T5]

**Provider一次情報**
- Deloitte / Accenture / NTT DATA等がStrategy〜Build / Integrationを公式Offeringとして持つ。[P2][P3][P4]

**当資料の分析仮説**
- High Decision AltitudeではStrategy / Governance / Organizational AcceptabilityのWeightが上がる。
- Consulting AnalyticsがStrong Candidate、当チームはAnalytical WorkstreamではCompetitiveという評価。

## A01-04e.4. Speaker Note

このProfileでは、分析の巧拙だけではVendorを選びません。経営層を含む複数Stakeholderをどう合意形成し、変革全体をどう設計・Governanceするかが重要です。

大手Consulting AnalyticsはこのCapabilityを明示的にOfferingとして持っています。当チームは具体的なPredictive / Causal PoCでは価値を出せますが、全社TransformationのPrime Vendorとして優位だと主張するEvidenceは現時点ではありません。

したがって、ここでは無理に自社を強く置かず、必要ならConsulting / SI部門と組みながらAnalytical Workstreamを担う方が自然なPositioningです。

## A01-04e.5. 次頁への接続
