## A01-04e.3. Supporting Logic

### A01-04e.3.1. なぜこの6軸Profileなのか

この類型は全社AI / Data Strategy、Business Transformation、Target Operating Model、AI投資Portfolio、Organization / Process Change等を表す。

Decision Altitude、Problem Novelty、CriticalityはHigh。分析は重要でも案件全体の一部であり、Analytical ComplexityはMediumと置く。Solution StandardizabilityはLowで、複数部門を跨ぐ個別設計が必要。Implementation CouplingはMedium〜Highで、Technology / Process / Organizationへの接続も伴う。

### A01-04e.3.2. なぜこのSelection Weightになるのか

Webster & Wind / ShethはB2B購買をBuying Center / Joint Decisionを含む組織的意思決定として扱う。[T1][T2]

Decision AltitudeとCriticalityが高い本ProfileではExecutive / Business / IT / Procurement等が関与しやすく、Deal-specific Fit、Risk、Evidence、Relational / Governance、Organizational AcceptabilityをHighと置く。

Professional Serviceでは購入前品質を直接観測しにくく、Reputation / Experience / Resource Quality等のSignalが重要になる。[T4][T5]

### A01-04e.3.3. Consulting AnalyticsのPosition

Deloitte / AccentureはAI Strategy、Data Modernization、Engineering、Build / Scale等をEnterprise Transformation文脈で提供する。[P2][P3]

Strategy / Operating Model / Executive Alignment / Technologyを組み合わせられるためStrong Candidateとする。

### A01-04e.3.4. SIer AnalyticsのPosition

TransformationがEnterprise Architecture / Cloud / Core Systemと強く結びつく場合、SIerも強い。[P4]

ただしExecutive Alignment / Organization Changeが主要価値の場合、そのCapabilityは個社・部門差が大きいためCompetitiveとする。

### A01-04e.3.5. DS SpecialistのPosition

DS SpecialistはUse Case検証やAnalytical Workstreamでは有力だが、Prime ContractorとしてはExecutive Facilitation / Program Governance等が追加評価される。[P1]

そのためWorkstream Candidateとする。

### A01-04e.3.6. AI / Platform VendorのPosition

Platform起点でProcess Transformationを行う場合は有力になり得る。[P5] 一方Vendor-neutral Strategyや複数TechnologyのRoadmapではFitが下がるため条件次第とする。

### A01-04e.3.7. 当チームのPosition

当チームは具体的なPredictive / Causal PoCやAnalytical WorkstreamにはFitする。一方、現時点でEnterprise-wide Transformation Strategy、Executive Facilitation、Operating Model Design、大規模Program GovernanceのEvidenceは確認できていない。

従って、

> **Relative Weak〜Competitive。Analytical WorkstreamではCompetitive。**

とする。

### A01-04e.3.8. Relative Advantageの有無

Prime Positionで競争優位を主張するには、全社 / 事業Transformationの主契約実績、Executive-facing team、StrategyからPoCまでの競合勝ち等が必要である。現時点では未証明。

### A01-04e.3.9. 反証条件

- Parent SIerのConsulting Capabilityを一体利用でき、Transformation主契約実績がある
- Executive stakeholderを巻き込んだAI / Analytics Strategy実績がある
- Strategy〜Analytical PoCで競合勝ち実績がある

これらが確認されればPositionを上げ得る。

### A01-04e.3.10. Evidence / Inference区分

**Published Evidence:** Organizational Buying、Professional Service Signal。[T1][T2][T4][T5]

**Provider一次情報:** Deloitte / Accenture / NTT DATA / BrainPad / Palantir。[P1]〜[P5]

**当資料の分析仮説:** 本6軸Profile、8軸Weight、Consulting Analytics＝Strong Candidate、当チーム＝Relative Weak〜CompetitiveというPositioning。

## A01-04e.4. Speaker Note

このProfileでは分析の巧拙だけではVendorを選びません。複数Stakeholderをどう合意形成し、変革全体をどう設計・Governanceするかが重要です。当チームは分析Workstreamでは価値を出せますが、全社TransformationのPrime Vendorとして優位だと主張するEvidenceはありません。

## A01-04e.5. A01-04への示唆

> A01-04eは、Decision AltitudeがCorporate側へ上がるほど当チーム単独のAnalytical Positioningでは不十分になりやすいことを示し、A01-04無印の重点をOperational〜Business中心とする根拠になる。
