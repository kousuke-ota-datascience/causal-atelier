# 21. Slide 21｜因果推論PoCの分析プロセス

## 21.1. Message

**因果PoCでは、推定器を選ぶ前にCausal Question・Estimand・因果構造・Identificationを定義し、その後にEstimationと妥当性確認を行う。**

## 21.3. Supporting Logic

- Causal Question：どのTreatmentの、誰に対する、どのOutcomeへの効果を知りたいかを定義する。
- Estimand：ATE、ATT、CATE等、意思決定に必要な効果の対象を固定する。
- Causal Structure：交絡・媒介・Collider・時間順序を整理し、前提を可視化する。
- Identification：観測データと仮定からEstimandを識別できる戦略を定める。
- Estimation：識別されたEstimandを有限標本から推定する。
- Diagnostics / Sensitivity：仮定への整合性や仕様依存性を確認して解釈する。

- 補足論点：**因果推論では「推定する前の設計」が分析の意味を決めるため、IdentificationとEstimationを分離して扱う。**

## 21.4. Speaker Note

因果推論を「Propensity Scoreを使う」など手法起点で進めないことを強調する。
