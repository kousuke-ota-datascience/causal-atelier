# 26. Slide 26｜診断・感度分析とPoC成果物

## 26.1. Message

**因果PoCではEffect Estimate単体を成果とせず、Overlap・Balance・Pre-trend等の診断とSensitivityを合わせて、どこまで主張できるかを判断する。**

## 26.2. Chart

**チャートタイトル:** Effect Estimateを支えるEvidence Stack

Messageを説明・論証するための主たる視覚表現として、以下の構造を採用する。

### 26.2.1. Chart Structure

- 既存の論理フロー／概念図を主チャートとして用い、要素間の関係・順序が一目で追える構造にする。

```text
          Business Interpretation
                 ▲
          Sensitivity / Refutation
                 ▲
        Diagnostics / Assumption Check
                 ▲
       Effect Estimate + Uncertainty
                 ▲
 Identification Strategy / Assumptions
```

**PowerPoint上の配置・強調**

- 5層のEvidence Stackを下から上へ積み上げる。
- Effect Estimateを中央に置きつつ、上下のAssumption / Validationを同程度に強調する。
- 最上段をBusiness Interpretationとし、意思決定へ接続する。

### 26.2.2. Chart内の最小表示テキスト

実際のPowerPoint上では、以下のラベル・短文を中心に表示する。Supporting Logicの全文をスライド上へ掲載しない。

- Business Interpretation
- Sensitivity / Refutation
- Diagnostics / Assumption Check
- Effect Estimate + Uncertainty
- Identification Strategy / Assumptions

## 26.3. Supporting Logic

- Diagnostics：Covariate balance、overlap / positivity、weight distribution、effective sample size、pre-trend等を設計に応じて確認する。
- Refutation / Placebo：結果が明らかに不適切な対照条件でも再現してしまわないかを確認する。
- Sensitivity：未観測交絡、調整集合、window、trimming、Estimator等への依存性を調べる。
- 成果物にはCausal Question / Estimand、DAG / assumptions、Identification Strategy、Effect Estimate、診断、Sensitivity、主張可能範囲を含める。
- Go / Additional Validation / No-Goは、効果量の大きさだけでなくEvidence Stack全体で判断する。

- 補足論点：**「効果が出た」ではなく、「どの前提のもとで、どの程度頑健に、その効果を主張できるか」をPoC成果とする。**

## 26.4. Speaker Note

因果PoCの科学的品質を示す締めのスライド。統計的有意差だけを成功基準にしない。
